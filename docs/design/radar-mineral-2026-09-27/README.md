Radar — palette claire minérale
================================

La couronne, les graduations et le balayage utilisent une palette ardoise / indigo grisé / violet discret en thème clair. Le fond est neutralisé. La palette sombre et les couleurs de gravité restent conservées.

En-tête sur deux lignes compactes pour éviter le vide créé par le retour à la ligne du conteneur horizontal en grande largeur.

Validation : compilation de l’exemple preview avec toutes les fonctionnalités ; captures natives des deux thèmes à 1100 points de largeur, données fictives.
